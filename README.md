# 内在坐标

一份无需构建、可直接打开的单页人格偏好探索工具。

## 使用

直接打开 `index.html`，或在本目录启动任意静态文件服务器。

## 设计边界

- 48 道原创题项，E–I、S–N、T–F、J–P 四维各 12 题，每侧各 6 题。
- 使用五级同意度与连续计分；四字母只是结果速记。
- 恰好落在中点的维度以 `X` 保留，不强行分型。
- 包含作答速度、中性回答比例、答案多样性与 8 组对应题的一致性提示。
- 题目和 16 型中文刻画均为独立撰写，不复制官方 MBTI® 测评题。
- 这是未经常模与信效度验证的自我探索工具，不可用于诊断、招聘或人员筛选。
