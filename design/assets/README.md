# 插画素材

二十幅工笔插画（ChatGPT 生成），是全站唯一的彩色。

| 目录 | 内容 |
|---|---|
| `raw/` | 原图（PNG，按编号与拼音重命名） |
| `illustrations/` | 处理后的 WebP：`NN-name.webp` 大图（长边 ≤ 1320px），`NN-name-sm.webp` 缩略图（长边 ≤ 440px） |
| `process.py` | 处理脚本 |

```bash
python3 design/assets/process.py design/assets/raw design/assets/illustrations   # 需要 numpy、Pillow、scipy
```

处理内容：主体 alpha 拉满、去掉四周几乎透明的雾；19、20 两幅原图把「透明格子」画进了像素，按灰白两色棋盘识别后去掉；裁边、缩放、导出 WebP。

示范页不再一章配一幅：二十幅放进同一个池子，每次打开页面随机抽取，隔一段放一张，印在宣纸下面。规则：面朝页面里面（朝右的放左边、朝左的放右边，山水楼阁不分）；同一次不重复，相邻两幅不同类；封面只抽朝右的人物或瑞兽。池子定义在 `design/songzhi/src.html` 的 `POOL`。
